# fashion_retail_store-sales-analysis
Task 6 
As part of my data analytics internship with Elevate Labs, I worked on a sales trend analysis project using MySQL. The goal was to examine monthly revenue and order volumes by leveraging SQL aggregation techniques. In this project, I extracted the month and year from order dates, grouped data accordingly, and applied aggregate functions like SUM() for revenue and COUNT(DISTINCT order_id) for order volume. Sorting the results helped in identifying trends, and I even explored how to get the top-performing months by sales. This task deepened my understanding of grouping data, handling NULL values, and using ORDER BY to structure results meaningfully. It was a great exercise in using SQL for time-based data analysis, and it prepared me for real-world analytical challenges.
